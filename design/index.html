touhou-stg-tools · Design system

デザインの見本

全ツールで使う色・文字・余白（デザイントークン）と、ボタンやカードなどの部品の見本です。値は design/ のファイルが正で、各ツールには scripts/sync_data.py で埋め込みます。

表示

色

色は必ずトークン（var(--accent) など）で指定し、#5856ef のような値を直接書かないでください。トークンを使えば、ライトとダークの切り替えも自動で効きます。

作品のテーマ色

data/games.json の hue（色相）から hsl(var(--h) var(--sat) var(--lit)) で作ります。彩度と明度はトークンなので、ダークでは少し明るくなります。

文字

新しいツールを作るとき

  1. <head> に下の 2 行を置き、その後ろに自分の <style> を書く。
  2. scripts/sync_data.py の DESIGN_TARGETS に HTML を足して実行する。
  3. 色・文字サイズ・余白・角丸はトークンを使う。足りない値は、まず design/tokens.css に足せないか考える。
  4. ページの最後に .foot で二次創作の表記を入れる。
